# UI Widgets Module

This directory contains modular UI components and telemetry widgets for the mobile client.

## Files

- **`status_badge.dart`**: Reusable pill badges indicating active Wi-Fi connection, server link status, and background mode.
- **`camera_card.dart`**: Information cards displaying sensor metrics (FPS, resolution, codec) for both the Rear and Front cameras.
- **`stats_sheet.dart`**: Bottom modal sheet providing manual server IP overrides, auto-discovery switches, and hardware concurrent camera capability inspection.
