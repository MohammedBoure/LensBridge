# User Interface Module

This directory contains the user interface views and screens of the Vision Cam application.

## Files

- **`home_screen.dart`**: Primary Flutter dashboard providing start/stop controls for background streaming, Wi-Fi connectivity telemetry, camera sensor cards, and settings triggers.
- **`widgets/`**: Sub-directory housing reusable modular UI components such as status badges, camera telemetry cards, and the settings modal sheet.
